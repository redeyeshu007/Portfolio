# Sudharsan — Software Engineer & AI Developer Portfolio

A modern, high-performance personal portfolio showcasing AI platforms, full-stack enterprise applications, client solutions, internship experiences, and national hackathon achievements.

## Tech Stack

- **Framework**: Next.js 16 (App Router, React 19, TypeScript)
- **Styling**: Tailwind CSS v4, tw-animate-css
- **UI Components**: Radix UI, Lucide Icons, Magic UI
- **Animations**: Motion (Framer Motion)
- **Content**: Content Collections (MDX Blog)
- **Deployment**: Vercel

## Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
