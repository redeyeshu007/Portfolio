# Building a Real Estate Management Platform from Scratch

Real estate runs on spreadsheets and missed follow-ups. I built a full-stack platform to replace both — a single place to manage properties, clients, and the people who handle them.

## The stack

- **React** on the front end for a fast, role-aware dashboard.
- **Node.js** API handling auth, business logic, and data access.
- A relational database modeling properties, clients, and users with clear relationships.

## Features that mattered most

- **Role-based access**: agents, managers, and admins each see exactly what they should — nothing more.
- **Inventory tracking**: every property's status, history, and documents in one view.
- **Client management**: leads, follow-ups, and deals tracked so nothing slips.

## What building it taught me

- **Authorization is harder than authentication.** Getting roles and permissions right took more care than the login flow.
- **Model the domain first.** Once the data relationships were right, the UI almost wrote itself.
- Real users want fewer clicks, not more features. Every screen got simpler over time.

Shipping a complete product — from schema to deploy — is a very different skill from building isolated features.
